# 点云处理的架子

搭建一个通用的点云处理框架，

1. 需要有主界面，主界面用于显示点云
2. 然后参数需要单独设计，设计能够通过配置文件加载并生成对应参数的界面（比如有的参数是范围参数，有的是单独的浮点参数，有的是文本参数，选项参数等等多种参数），需要好好设计配置文件的格式。
3. 需要有高级模式，高级模式模式里面可以开启单步调试算法，看到每一步算法的步骤，每一步可以弹出vtk，显示每一步处理的结果，并且处理结果都会高亮加粗。
4. 后续主界面、参数界面和算法库分开，都通过动态库的形式加载，写完算法直接把库丢进主界面的程序里面替换替换原来或者添加算法就可以了，这样后续我只需要写算法就行了并不需要关系界面
