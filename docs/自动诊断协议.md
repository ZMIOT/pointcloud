# 自动诊断协议 v1

本规范是 [方案](主软件自动诊断与调参协议方案.md) 的可执行第一版，JSON Schema 位于 `schemas/`，宿主校验器为 `fw::Diagnostics`。协议版本与算法版本、参数版本分别管理。算法在 `parameterSchema()` 的顶层增加可选 `diagnostics`；执行结果在 `metrics.diagnostics` 增加可选报告。旧插件无这两个字段时照常运行。

## 档案

`protocolVersion=1`，`algorithmId` 与描述符 ID 一致，`algorithmVersion` 与描述符版本一致。`orderedInput` 说明输入是否要求保留采集点序；宿主的通用 XYZ 检查不能证明点序正确。`stages` 按实际流水线顺序列出稳定 ID/显示标签。`outputs` 为每个输出提供稳定 `id`、语义 `targetId`、可选 `targetLabel`、`role`（`measured`、`fitted`、`segmented`、`measurement`、`auxiliary`）和 `geometry`。数组顺序不是身份，运行报告中的 `cloudIndex` 才映射本次 `AlgorithmResult.outputs`。一个目标可有多个角色，同一角色也可有多个目标。

`codes` 定义稳定 `id`、所属 `stage`、默认严重程度和标签。`trialParameters` 只声明可试参数：`id` 必须存在于参数 schema，`stages` 是影响阶段，`step` 为单步探测量，`maySuppressPhysicalDefect` 表示可能掩盖真实瑕疵，并写明 `expectedChange`、`risk`、`cannotFix`。它们是作用假设，不是已验证建议。非数值参数、输入方向与没有证据支持的参数不自动试。

## 报告

报告必须携带同版本协议、算法 ID/版本、`input`（`cloudId`、`pointCount`、`coordinateFrame`、`unit`）、完整有效参数快照、`outputs` 身份映射及 `issues`。宿主只接受与当前运行输入、参数和输出数量一致的报告。每个 issue 含 `code`、`stage`、`severity`、`region`、`visibility`、`scope`、`summary`、`evidence`。`scope.targetId` 与 `scope.outputRole` 定位目标；`summary` 只用于显示，规则不能解析它。

输出映射可附 `statistics.sampleCount`、`segmentCount`、`interpolatedCount`。这些计数用于发现试跑变化或退化线索，不能单独作为准确性分数，也不表示轨迹连接拓扑已完成验证。

`region.kind` 可为 `whole`、`point_index`、`section_range`、`bbox`。`point_index` 引用本次原始输入索引；`section_range` 的 `first/last` 只是算法本次恢复的截面编号，还必须给世界坐标 `representative=[x,y,z]`，跨试跑不能只用截面编号配对。`bbox` 的 `min/max` 为世界坐标。未来扩展曲线段或多边形需升级协议或加可选字段及校验。

`visibility` 值为 `observable`、`missing_input`、`not_applicable`、`unknown`。`unknown` 不能被算作漏检，`missing_input` 不能通过数值参数“补出”证据。`evidence.support` 是非负整数，`supportUnit` 和 `basis` 必须交代统计口径。若给 `observed` 或 `limit`，两者必须为有限数且有 `unit`。严重程度只表示事件，不覆盖算法成功/失败状态。

`origin` 单独表示异常来源：`undetermined`、`input_missing`、`acquisition_noise_suspected`、`physical_defect_suspected`、`physical_defect_confirmed`、`algorithm_error_confirmed`。这是来源状态而非可观测性；未经人工标注或独立证据，算法应上报 `undetermined`，不能凭局部不规则就断言产品瑕疵或算法错误。疑似/确认物理缺陷不触发自动参数规划；隔离试跑可以保留供人工复核。未判明/疑似缺陷条目消失、身份丢失、输出统计变化等情形需要人工复核，不算改善。`maySuppressPhysicalDefect=true` 的参数不提供一键采用，用户复核后仍可手动设置。

档案最多 64 KiB，报告最多 256 KiB、128 条 issue；普通运行只上报聚合与代表位置。无效档案停用专有诊断但算法仍可运行；无效报告被拒绝并记录原因，不能成为推荐依据。

## 比较和建议边界

主软件先按 `targetId + role` 匹配输出，再对齐几何位置和原始索引，分别统计实测与插补、覆盖区段、断段和连接。结果点数、连续段数和算法质量评分都不足以证明正确。没有人工确认的参考边缘或合格标注时，试跑只能提供“待人工确认”的内部证据；缺测、目标不适用、输入方向错误和对齐不可靠时不给数值建议。采用参数是用户操作，试跑结果永不自动进入正式数据列表。
