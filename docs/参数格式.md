# 参数格式 v1

参数定义是框架自定义 JSON，不是完整 JSON Schema。UTF-8 编码；Qt Resource 默认随算法 DLL 发布。调试时可在 DLL 旁放置 `<DLL 文件主名>.parameters.json` 覆盖定义，ID 和参数版本必须与插件元数据一致。覆盖文件损坏时禁用算法并记录错误，不退回隐式默认配置。

顶层字段：`schemaVersion: 1`、稳定的 `algorithmId`、正整数 `parameterVersion`、`title`、`groups`。每个分组包含唯一 `id`、`title`、`parameters` 数组及可选 `advanced`。

参数的 `id` 在整个算法内唯一；`label` 只用于显示。每个参数必须有 `type` 和合法 `default`。通用可选字段：`description`、`unit`、`advanced`、`visibleWhen`、`enabledWhen`。修改标签不需要修改 ID；改变参数含义、删除或重命名时应提升参数版本，并提供迁移函数。

| type | JSON 值 | 可选约束 / 显示设置 |
| --- | --- | --- |
| bool | true / false | — |
| int | 32 位整数 | min、max、step |
| double | 有限数值 | min、max、step、decimals（0..15） |
| string | 字符串 | required、maxLength、pattern、multiline |
| enum | 字符串 / 数值 / 布尔 | options: [{value,label}]，值不得重复 |
| range | {lower,upper} | 必须有 valueType: int / double；数值约束同上 |
| file | 路径字符串 | required、mustExist、filter（Qt 文件过滤器） |
| directory | 路径字符串 | required、mustExist |
| vector3 | [x,y,z] | min、max、step、decimals |
| color | [r,g,b,a] | 四个 0..255 整数 |

`min/max` 是可输入边界，`lower/upper` 是用户填写的范围。数值单位为显示说明，框架不做隐式单位转换。正则匹配整个字符串。文件存在性在编辑/运行时校验，定义加载不要求默认路径存在。

联动条件格式：

```json
{
  "all": [
    {"parameter":"enabled","operator":"eq","value":true},
    {"any":[
      {"parameter":"method","operator":"eq","value":"ransac"},
      {"parameter":"iterations","operator":"gt","value":100}
    ]}
  ]
}
```

`eq/ne` 按 JSON 值比较；`lt/le/gt/ge` 只比较数值。`all/any` 需要非空数组。非法引用和参数间循环依赖在定义加载时拒绝。联动只控制界面，禁用或隐藏字段的值仍然保留、传递并校验；涉及业务关系的验证在算法 `validate()` 内实现。

预设格式：

```json
{
  "algorithmId":"cloud.sample_pipeline",
  "parameterVersion":1,
  "values":{"name":"我的平面","leaf_size":0.02}
}
```

缺失字段补默认值；未知字段提示并忽略；同版本的非法字段值拒绝加载。版本变化时先调用插件 `migrateParameters`，再执行当前版本校验。迁移失败不会部分覆盖当前面板；“默认值”按钮可恢复新版本配置。文件写入使用 QSaveFile，避免半写入文件。
