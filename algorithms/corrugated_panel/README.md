# 波纹板特征提取（任意空间姿态的平面/缓变局部平面）

插件 ID：`custom.corrugatedPanelFeature`。输入一份 XYZ 点云，输出：

1. `A 基准面`：沿工件长度方向建立的 A1～An 局部基准面内点集合；各段独立拟合，允许首尾不共面；
2. `B 最佳切片`：A 面两侧 10/20/30 距离、3 厚度切片中去噪后最长且最完整的弯折切片；
3. `C 投影候选点`：B 中所有点到 A 面的正交投影；
4. `实测曲线（C 恢复）`：由 C 恢复出的连续曲线，保留原始弯曲形状，不做直线化；
5. `拟合直线控制点`：根据实测曲线的平滑切向斜率识别连续水平、上坡和下坡区段；每个连续状态只做一次正交最小二乘直线拟合，相邻两条拟合直线的交点作为唯一转换点；
6. `白色均匀点`：按目标间距从实测曲线选取真实轨迹点，再把这些真实点统一正交投影到该区段唯一的拟合直线上；全部转折角点会原样强制加入。

所有距离均使用输入点云坐标单位。需求数据默认毫米；点云格式本身无法可靠携带单位时，需要在导入和参数中保持一致。

## 需求歧义的处理

原始需求第 2、3 步文字重复，但“长直时跳到第三步 / 长直时报错”的组合表明它们分别处理 A 面的两侧。本实现先评估法向正侧；该侧三个切片均为直线时自动评估负侧，两侧都没有弯折切片才失败。若两侧都有弯折，按长度、覆盖完整度和支持点数综合选择。

## 算法与并行

- 先从最多六个 RANSAC 候选平面中选择能把点云分到两边的 A 面种子，再确定长度方向，并按 `局部基准面最大长度` 自动建立 A1～An。各段独立 RANSAC/PCA 拟合，法向保持同向但不要求共面；任一区段缺少足够支持点时明确失败。
- xoy、xoz、yoz 和法向在 XYZ 三轴上均有分量的斜面使用同一套三维向量计算。每个 Ai 都建立右手正交局部坐标系：局部 X 为投影到 Ai 的工件长度方向，局部 Z 为 Ai 法向，局部 Y 为 `Z × X`。该计算等价于先把 Ai 刚性变换到局部 xoy，再把输出逆变换回输入世界坐标；不交换全局坐标轴，也不改变距离阈值和单位。
- 每个局部坐标系的原点、X/Y/Z 轴、平面 RMS 和相邻法向变化角都会写入运行指标。相邻 Ai 的法向变化超过 `相邻 A 面最大法向变化角` 时明确失败，避免将突变或明显曲面静默展平。
- 10/20/30 距离切片和 B→C 投影都会按点的长度位置选择对应 Ai；边界按唯一主区段归属，不会把长工件全部投到单一全局平面。
- 六个切片并行提取；切片内使用半径邻域滤除孤立噪声，再用二维主轴残差和协方差判定长直/弯折。
- B 投影和 RANSAC 计数在 OpenMP 可用时使用多核；`线程数=0` 使用运行库默认值。
- 实测曲线显示为绿色，拟合直线显示为红色，两者都是独立输出，不会互相覆盖。
- `坡段合并容差` 默认值为 `3.0`。算法不再按局部距离误差递归拆线，而是对蓝色实测轨迹的切向斜率做平滑、抗噪和最小段长合并：连续上坡只对应一条直线，连续下坡只对应一条直线，连续水平段也只对应一条直线。每段使用该段全部实测轨迹点整体拟合，相邻线的交点作为段间转换点。`白色点目标间距` 只负责从真实轨迹中选点，选中的点再统一投影到该整段直线；白点显示为白色。
- 生成点云带 `is_corner` 字段：转折点为 `1`，普通均匀点为 `0`。短线段即使小于目标间距也保留两端角点，所以角点附近的实际间距可以小于目标值。
- 输出 A/B 通过原始索引复制，保留输入自定义字段；C/最终轨迹增加 `source_index` 字段。

## 构建与验证

主工程已通过 `add_subdirectory(algorithms/corrugated_panel)` 嵌入本库。常规主工程构建会生成 `CorrugatedPanelCore` 和 `CorrugatedPanelAlgorithm.dll`，并运行 `corrugated_panel_core` 合成回归测试。测试覆盖正侧波纹、正侧直线后切换负侧、双侧直线报错、投影共面、等弧长均匀化和取消。

当前阶段没有带人工真值的波纹板样本标注，因此不宣称识别准确率；真实数据仍需用 A/B/C 分阶段调试图确认方向、单位和默认阈值。“任意姿态”只表示同一几何输入做刚性旋转和平移后应得到等价结果，不表示能够用单个刚性变换无失真地展平明显曲面。

合成回归会把同一份 xoy 数据刚性变换到 yoz、xoz、法向三分量均非零的任意斜面，并覆盖大平移、法向符号二义性及 A1 与 An 不共面的长工件。所有结果逆变换后比较 A/B 支持点、C、实测轨迹、拟合角点和白点，最大位置偏差使用 `max(1e-6 × 包围盒对角线, 1e-4 个坐标单位)`。这验证坐标等价性，不代替真实工件定位精度验收。

1.5.1 修复局部区段存在更密集非 A 平面时的误选：局部 RANSAC 与全局 A 面使用相同的“两侧分布”语义；若连续多个区段跳到另一平面后又回到前后相互一致的基准面，算法会用两端趋势引导这些区段重新使用本地实测点拟合，而不是复制邻段平面。合成回归覆盖单个和连续多个干扰区段。`121.txt` 默认六段实跑中，修复后的异常段支持点为 194139、RMS 为 0.165031、相邻法向变化为 0.100773°；1500 mm 两段配置也已运行通过。这些数值是该样本的内部一致性证据，不代表通用定位精度。

1.5.2 修复首尾局部基准面只有一个相邻区段时无法识别密集干扰平面的问题。局部候选相对全局种子或已建立相邻 A 面的法向变化若超过连续性搜索范围，将不再被选为 A 面。`6.txt` 两段实跑由 A1/A2 法向突变 37.0682°、处理失败，恢复为 2.68061° 并完成轨迹拟合；新增仅在首段布置密集斜面的双区段回归。该样本结果属于运行一致性证据，不替代人工真值精度验收。

1.5.3 进一步修复 `6.txt` 在 1.5.2 中“能够处理但 A1 支持不足”的问题。仅限制随机候选角度无法保证找到正确的 A 面；现在将全局种子/相邻 A 面作为显式初值，在本区段实测点上迭代拟合，并与随机候选按同一全量点内点数、两侧分布和方向评分比较。各段仍独立拟合，不强制共面。默认参数实跑：A1 支持点从 8635 增至 130562，RMS 从 0.344959 降至 0.179733；A2 支持点 157306、RMS 0.163447；相邻法向差 0.531757°，边界间距约 0.221758 mm。前一版仅以运行成功判断修复完成是不充分的。

运行统计新增 `boundary_gap_measured` 和 `boundary_gap_from_previous`。边界间距是在交界附近输入点横向 5%/50%/95% 分位位置，沿全局种子法向测得的两平面最大间距（输入单位）；没有前一段或边界点不足时为未测量/null。该指标用于人工质量复核，尚未新增全局通用的间距拒绝阈值。

真实样本回归通过环境变量 `BWB_SAMPLE_6_PATH` 指定原始 `6.txt`，运行 CTest 的 `corrugated_panel_sample6`；未设置时明确跳过。它检查每段支持量、长度覆盖、RMS、相邻角度、边界间距及 C 点落在所属 A 面上。相关阈值只防止已知样本退化，不代表人工真值精度验收。`CorrugatedPanelInspect` 的输出目录传 `-` 时只打印统计，便于更换分段长度而不生成大体积点云文件。

1.5.4 修复 `52.txt` 的全局 A 面种子误选。此前只按内点数乘以两侧平衡权重评分，斜穿点云厚带的候选会胜过真实表面。现在对全局候选和局部最终候选计算集中支持量：核心带 `|distance| <= t` 的点数，扣除肩带 `t < |distance| <= 3t` 点数的一半（两带宽比为 1:2），再应用原有方向和两侧分布权重。这是几何候选评分，不是正确概率。检查器同时输出每个全局候选的支持点、正负侧点数、RMS 和集中支持量，便于复查误选原因。

`52.txt` 默认参数实跑：A1/A2 支持点 88696/107304，RMS 0.157616/0.160006 mm，相邻夹角 0.425005°，边界间距 0.12586 mm，所选弯折切片完整度从 0.325 提升至 1，并恢复另一侧完整直线切片。新增 `BWB_SAMPLE_52_PATH` 指定的 `corrugated_panel_sample52`，以及厚带干扰/任意旋转合成回归；真实样本同时经过插件 float 点云路径检查。`6.txt` 与 `121.txt` 的既有结果同步回归。样本指标仍仅是内部几何与已知退化回归证据。

可脱离界面检查 `index x y z` 文本点云：

```powershell
./build/bin/Release/CorrugatedPanelInspect.exe input.txt output-directory
```

检查器输出 A1～An 的数量、长度范围、点数与平面系数，以及六个切片的点数、长度、完整度、偏差和弯折判定；并在指定目录写出 `a_plane.xyz`、`b_slice.xyz`、`c_projected.xyz`、`measured_curve.xyz`、`fitted_line.xyz` 和 `white_points.xyz`。
