# 焊缝识别插件 1.0.0

退出点云工作台，将包内 `plugins/algorithm/FrameSeamAlgorithm.dll` 放到工作台同名目录，然后重新启动。选择“焊缝识别：单帧轮廓 + 邻帧局部面”。参数定义已嵌入 DLL。

本插件必须使用与宿主一致的 FrameworkSDK 及依赖构建，当前为 Windows x64 Release / MSVC v142 / Qt 5.14.1 / PCL 1.11.0 / VTK 8.2 / OpenCV 4.2。只支持兼容构建标识的工作台。不修改或覆盖宿主的第三方库。

输入为完整有序的原始扫描 PCD/PLY；参数中选择逐点匹配的 manifest.json，索引引用的原始帧文件需保留在索引同目录。不能将之前提取出的左右焊缝结果作为原始扫描输入。长度参数沿用点云坐标单位，样例默认毫米，不自动换算。

运行后生成左右两个结果点云；结果带有 confidence 和 segment_id 字段，显示按段连接，不跨缺失段画线。可使用工作台导出 PCD 保存这些字段。

高级模式下开启单步调试，可查看六个主要检查点；参数“调试详细程度”还可切换逐帧快照。检查点可以下一步、继续或停止。

该插件迁移的是原项目的默认方案3；参考方案1、未实现的方案2、原历史管理和 HTML 报告程序不包含在此 DLL 中。
