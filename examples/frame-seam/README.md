# 本机焊缝插件示例

这个目录包含原项目完整原始扫描的 PCD 转换件，以及已填写帧索引路径的参数预设。

1. 重启工作台，选择“焊缝识别：单帧轮廓 + 邻帧局部面”。
2. 导入本目录 `original_scan.pcd`，单位选 `mm`。这是 704,808 点的完整原始扫描，不是之前导出的单条焊缝。
3. 在“参数预设 → 加载预设”中选择本目录 `parameters.preset.json`。
4. 点击运行。需要单步时，先勾选高级模式，再勾选启用单步调试。
5. 预期得到左右两个结果，分别为 565 点、384 点。主要步骤模式产生 6 个检查点。

该预设的 `manifest` 指向本机 `E:/CODE/extractFeature/frame_data/20260907_001/manifest.json`；该目录中的原始逐帧文件必须存在。源目录未修改。示例没有复制全部逐帧数据，不是脱离原数据目录即可运行的完整数据包；更换机器或移动数据后，请重新选择索引路径，并携带其引用的全部帧文件。

PCD 转换保持原始 XYZ 和点序，已经与帧索引逐点核对；点云单位是人工元数据，重新打开文件仍需选择 `mm`。当前参数沿用原算法的毫米默认值，不自动换算单位。

算法开发入口见 [独立焊缝算法工程](../../algorithms/frame_seam/README.md)。
